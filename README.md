# ونسة — الدخول بحساب Google

## تفعيل الدخول (مرة واحدة)
1. Firebase Console ← Authentication ← Sign-in method ← **Google** ← فعّله واختر بريد الدعم ← حفظ.
2. Authentication ← Settings ← Authorized domains ← أضف نطاق موقعك (مثل `username.github.io`).
3. Firestore Database ← Rules ← الصق محتوى `firestore.rules` ← Publish.

لا يحتاج هذا إلى خطة Blaze ولا إلى فوترة.

## كيف يجد الأصدقاء بعضهم
بالبريد الإلكتروني. اضغط + واكتب بريد صديقك على Google، ويجب أن يكون قد دخل إلى ونسة مرة واحدة.

## الميزات
- الإعدادات (زر الترس): الوضع الليلي/النهاري، سمة لون الرسائل، حجم الخط، خلفية المحادثة، اللغة (العربية/English)، الخصوصية (إخفاء متصل الآن، إيصالات القراءة)، صوت الرسائل، Enter للإرسال.
- القصص: صورة أو نص، تختفي بعد 24 ساعة، يراها من بينك وبينه محادثة. بعد تحديث الملفات انشر `firestore.rules` مرة أخرى.
- لا يوجد "آخر ظهور". تظهر فقط حالة "متصل الآن" ما لم تُخفِها.
